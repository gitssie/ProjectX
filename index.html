An environment,
not a bag of toggles.

XenSpace treats identity values as a system. Hardware, display, locale, carrier, network, and app-scoped identifiers move together so target apps observe one believable device.

Coherent identity

Device model, system version, screen geometry, network properties, and identifier lifecycles resolve as one profile.

Lifecycle-aware scope

Stable values remain stable for the right duration: profile, vendor, boot session, permission state, or app installation.

Local by design

No account, subscription, LAN control plane, or remote service. The installed UIKit app is the only control surface.
